03

Student Profile & Skill Verification Chips (GET /students/{sid}, _skill_chips.html)

Executive header, categorized skill chips with verification badges and provenance tooltips, and cascading staff-only deletion.

student faculty_mentor tpo_admin
Verification Badges & Provenance (_skill_chips.html)
  • verified: Green badge (Verified (score)) when verified in mock interview or evidence contains interview verified.
  • claimed: Neutral badge (Claimed) for resume-extracted skills awaiting interview verification.
  • needs_reverification: Amber badge (Needs Re-verification) + Re-verify Skill link to /students/{sid}/interviews.
  • unverified: Red badge (Unverified) for interview remedial gaps + Re-verify Skill link.
Evidence, Confidence & API Payload (_skill_payload)

Skills are grouped by taxonomy category via _group_skills() and rendered inside #skill-chips with proficiency badges (advanced, intermediate, basic), mention counts (xN), and native title tooltips displaying extracted evidence lines.

GET /api/students/{sid} and GET /api/students/{sid}/skills expose confidence (float, default 0.5), last_verified_score, source ("resume"), verification_status, and evidence.

Control / Route Guard / Scope Behavior
Header Quick Actions profile.html Displays PII redaction badge ({N} PII redacted when > 0), Executive Summary, and links to View Job Matches, Upskilling Plan, and Mock Interview.
#delete-profile-btn & POST /students/{sid}/delete require_role("tpo_admin") + enforce_student_scope Rendered only when role != 'student'; prompts via window.confirmAction(), submits #delete-profile-form, calls delete_student_core(), and redirects (303) to /.

Resume Re-upload Gate, Resume X-Ray & AI Bullet Improver

HTMX in-place skill refresh, single-use student re-upload unlock workflow, deterministic ATS X-Ray, and zero-hallucination STAR bullet rewrites.

student (1-time unlock) tpo_admin (direct)
Feature / Control / Route Functions & Guards Behavior & Workflow
HTMX Re-upload (hx-post="/students/{sid}/resume") pages.py:reupload, create_student_core_resume(), POST /api/students/{sid}/resume Targets #skill-chips (hx-swap="innerHTML"); #reupload-btn shows Extracting... spinner on htmx:beforeRequest. Re-parses, scrubs PII, sanitizes, replaces StudentSkill rows, updates vector store, and refreshes persisted JobMatch rows via _rank_and_persist() if matches exist.
Student Re-upload Lock & Request (#resume-locked-card, #reupload-request-form) POST /api/students/{sid}/resume-reupload-request (student, tpo_admin) Once a student has a stored resume, uploads lock to preserve audit integrity. Submitting #reupload-request-reason + #request-reupload-btn creates an ApprovalRequest (kind="resume_reupload_request", status="pending_review"; HTTP 409 if duplicate pending) and logs student.resume_reupload_requested; UI displays #reupload-pending-banner until TPO approves.
Single-Use Gate Enforcement enforce_resume_reupload_gate() & consume_resume_reupload_unlock() After TPO approval sets resume_reupload_unlocked=True, the student sees the unlocked upload form. Non-tpo_admin callers without an unlock receive HTTP 403. Upon successful re-upload, consume_resume_reupload_unlock() resets resume_reupload_unlocked=False and logs student.resume_reupload_consumed.
Resume X-Ray (GET /api/students/{sid}/resume/xray) students.py:resume_xray → app/resume/xray.py:xray_resume() Deterministic (no-LLM) ATS readiness score (0–100) weighted across impact_quantification (30%), action_verb_strength (25%), skill_density (25%), and section_completeness (20%), plus detected sections, links, and metrics.
AI Bullet Improver (POST /api/students/{sid}/resume/improve-bullets) students.py:improve_resume_bullets → pick_weak_bullets() + improve_weak_bullets() Selects up to 3 weakest bullets (25–300 chars, non-header/contact/skill-list, missing metrics or action verbs) and prompts ctx.llm (IMPROVE_BULLETS_SYSTEM) constrained strictly to present_skills (zero-hallucination). Returns {"ats", "improvements"} (HTTP 503 if LLM is unconfigured).
