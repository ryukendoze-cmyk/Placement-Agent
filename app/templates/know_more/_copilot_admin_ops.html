API Routes (copilot.py)

  • GET /copilot — copilot_page() renders copilot.html with role-scoped student list, QUICK_PROMPTS, and active sop_ids().
  • POST /api/copilot/ask/stream — copilot_ask_stream() (rate-limited: copilot_ask). Accepts question, optional student_id, optional job_id, history. Emits SSE events: retrieval (immediate sources + trace), : ping keep-alives every 2s during LLM synthesis, token (3-word chunks), and complete (annotated answer, citations, agent_run_id).
  • POST /api/copilot/ask — copilot_ask() synchronous JSON endpoint used as automatic fallback when ReadableStream / SSE fails.
  • GET /api/students/{sid}/eligibility/{job_id} — student_job_eligibility() one-click eligibility check guarded by enforce_student_scope, returning evaluate_student_eligibility() JSON (404 if student/job missing).

RAG, Eligibility & Grounding (policy_rag.py)

  • Hybrid Retrieval (search_sops): Combines exact SOP-XX regex pinning (s_exact = 1.0), stop-word-filtered lexical overlap (0.55 × s_lex), and dense cosine similarity (0.45 × s_dense) over index_sops(). Returns status="out_of_scope" below relevance floor (min_score=0.14).
  • Safety & Telemetry: _sanitize_copilot_question() scrubs PII (scrub_for_llm) and blocks prompt injections (sanitize_untrusted_text → audits security.prompt_injection_blocked). _copilot_synthesis() strips raw job IDs (_clean_job_ids), checks SOP IDs (verify_policy_citations) and numeric bounds (verify_sop_numeric_claims), persists AgentRun/AgentStep (_record_copilot_agent_run), and logs copilot.asked.
  • Explainable Eligibility Gate (evaluate_student_eligibility): Evaluates SOP-03 (gpa_cutoff + tier backlog limits), SOP-09 (branch_restriction via is_branch_eligible), SOP-04 (tier_mock_gate vs min_mock_score), SOP-05 (skill_readiness vs min_coverage_pct & blocked_band), and SOP-08 (flags unverified skills).

LLM Providers & Circuit Breaker

get_llm() routes to BedrockLLM (converse/converse_stream), OpenAILLM (streaming-first with 429 backoff + _direct_complete fallback), or deterministic offline MockLLM (handles 14 TASK: prompts). get_instrumented_llm() wraps them in TelemetryLLM + LLMTelemetryTracker: logs tokens & USD cost (PRICING_USD_PER_M) and trips a circuit breaker after 3 failures in 60s for a 30s cooldown on MockLLM (complete_live() blocks mock fallback).

Embedder & VectorStore Backfill

LocalEmbedder loads sentence-transformers/all-MiniLM-L6-v2 (384-dim, respects HF_HUB_OFFLINE=1) and falls back to deterministic HashingEmbedder(dim=384). PgVectorStore persists Vector(384) rows with HNSW cosine index (ix_embeddings_hnsw, graceful sequential-scan fallback). On SQLite/tests, MemoryVectorStore is warmed at startup by backfill_memory_vectors(ctx) in main.py.

Background TaskQueueManager

Executes async scraping, OCR, and campus drive cohort re-matching outside the request path, tracking TaskState (queued | running | completed | failed, progress_pct). Uses in-process ThreadPoolExecutor(max_workers=4) (capped at 2000 states) for TASK_BACKEND=memory, or a Redis list + BRPOP(timeout=1) daemon consumer for TASK_BACKEND=redis with automatic fallback to memory if Redis is unreachable.
