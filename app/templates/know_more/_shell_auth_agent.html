JKLU Institutional Portal, Auth Modes & Strict Middleware

Public + Auth login.html · auth.py · main.py
Route / Component Handler / Source Behavior & Validation Rules
GET /login auth.login_page Renders auth/login.html with #jklu-login (#email, #pin) and #theme-toggle. When show_demo_controls (demo_role_switch && auth_mode != "strict"), exposes #judge-personas (.judge-persona-btn), #student-personas (.student-fast-btn), and #fast-login (.fast-role-btn).
POST /auth/login auth.auth_login Enforces @jklu.edu.in domain (403 otherwise). Verifies PIN via _verify_pin() using pbkdf2_sha256$<iters>$<salt>$<hash> + hmac.compare_digest against data/personas.json (or demo_pin "2026"). Auto-provisions Rohit Shetty via _ensure_rohit_shetty() if absent. Sets signed ps06_session + legacy ps06_role cookies (httponly=True in strict mode, samesite="lax") and logs auth.login.
POST /auth/logout auth.auth_logout Logs auth.logout (pseudonymized via mask_email), deletes ps06_session and ps06_role cookies, and returns 303 redirect to /login.
POST /api/auth/switch-role auth.switch_role Switches active role & claims; returns 403 in strict mode when demo_role_switch=False. Logs auth.role_switched (or auth.denied).
GET /api/auth/role auth.get_role Returns resolved role, valid roles tuple, and serialized CurrentUser (or null in open demo mode).
rbac_strict_and_audit_middleware main.py In auth_mode="strict", blocks unauthenticated non-public routes (401 JSON for /api/*, 303 → /login for HTML). Public allowlist: _PUBLIC_EXACT (/login, /healthz, /readyz, /manifest.webmanifest, /sw.js, /api/campus-drives/public-jnf) and _PUBLIC_PREFIXES (/auth/, /static/, /jnf/, /api/campus-drives/public-jnf/). Audits 401/403 responses via _audit_auth_denied_rate_limited() (10s window per actor/path/status).

ReAct Engine, 18-Tool Registry & Zero-Hallucination Verifier (orchestrator.py, tools.py, verifier.py)

  • Plan → Execute → Verify → Recover: _sanitize_goal_text() scrubs PII and blocks prompt injections; _plan() generates 2–5 steps (with _fallback_plan() safety net). _execute_loop_iter() resolves $first/$last/$prev/$<tool>.<key> refs, enforces server-side _inject_role_args(), caps execution at MAX_EXECUTED_STEPS=8 and dynamic replanning at MAX_INJECTED_STEPS=3, and retries failed calls once via _repair_failed_step() (TASK: repair_step; never retries PermissionError).
  • 18 Registered Tools (TOOL_REGISTRY + TOOL_ALIASES): inspect_student_profile, rank_and_explain_jobs, simulate_skill_acquisition, search_placement_policy_rag, search_course_catalog, generate_prerequisite_roadmap, audit_resume_bullets, query_cohort_bottlenecks, draft_cohort_intervention, propose_hitl_approval, check_drive_eligibility, persist_upskilling_plan, inspect_interview_history, search_live_market_jobs, purge_live_market_jobs (TPO/Faculty only), ask_clarifying_question, submit_drive_application, simulate_placement_drive.
  • Grounding Verifier (verifier.py): build_known_entities() + verify_text() / verify_json() validate every job-, course-, SOP-, run-, appr-, stu-, int-, and plan- ID plus URLs and verify_sop_numeric_claims() (SOP-01/03/04/05/10/14 thresholds). Unverified tokens are annotated inline as [UNVERIFIED: x] and scored via grounding_score.

Enterprise Security Modules & PWA / Desktop / Mobile Packaging

Security & Packaging app/security/* · sw.js · desktop/ · mobile/
Module / Platform Key Symbols / Files Capabilities & Enforcement
RBAC & Row-Level Security app/security/rbac.py ROLES hierarchy (student < faculty_mentor < tpo_admin via _IMPLIES). CurrentUser binds student_id strictly to student. encode_session / decode_session sign cookies with HMAC-SHA256 + iat/exp. require_role() & enforce_student_scope(request, sid) block cross-student and cross-department access (403).
PII Redaction & Pseudonymization app/security/pii.py detect_pii, redact_pii, scrub_for_llm strip EMAIL, AADHAAR, PAN, PHONE, and ADDRESS into [REDACTED_<KIND>] before storage or LLM calls. mask_email, audit_actor_ref, sanitize_audit_entry hash emails into irreversible id-<8hex> refs.
Prompt-Injection Guardrails app/security/guardrails.py sanitize_untrusted_text() neutralizes 11 regex injection patterns ([REDACTED_INJECTION_ATTEMPT]) and triggers security.prompt_injection_blocked audits. wrap_untrusted_xml() escapes closing tags; verify_extracted_skill_grounding() enforces SOP-08 resume skill grounding.
Sliding-Window Rate Limiter app/security/ratelimit.py Thread-safe RateLimiter keyed by (identity, bucket) with DEFAULT_LIMITS: jobs_scrape (10/60s), agent_run (30/60s), copilot_ask (60/60s). check_rate_limit() returns HTTP 429 + Retry-After when rate_limit_enabled=True.
Append-Only Audit & Startup audit.py · main.py log_audit() stages immutable AuditLog rows guarded by install_audit_guard SQLAlchemy listeners. main.py configures CORSMiddleware (localhost + capacitor://localhost) and runs backfill_memory_vectors(ctx) on startup.
PWA Offline Shell sw.js · manifest.webmanifest jklu-careeros-v2 precaches vendored JS/CSS/icons (cache-first), never caches /api/ or /auth/, and uses network-only (no-store) for navigation with an offline HTML fallback so role HTML never leaks across sign-outs.
Desktop (Electron v45) desktop/main.js · preload.js jklu-careeros-desktop (in.edu.jklu.careeros.desktop) auto-spawns uv run uvicorn app.api.__main__:app on port 8010, persists URL in careeros-settings.json, exposes window.careerosDesktop IPC bridge, and builds Windows portable/NSIS installers.
Mobile (Capacitor v6.2 Android) mobile/capacitor.config.json jklu-careeros-mobile (in.edu.jklu.careeros) wraps www/ for Android with cleartext: true, allowMixedContent: true, and cap:sync / cap:open scripts.
