API Routes & Telemetry

  • POST /api/students/{sid}/plans — Solves & persists plan (requires ctx.llm, 503 if unset; defaults to top JobMatch). Audits plan.generated.
  • GET /api/students/{sid}/plans & GET /api/plans/{plan_id} — Returns _serialize_plan() with BKT, ROI, alternatives, CPM DAG, sprint swimlanes, and SOP gates.
  • POST /api/plans/{plan_id}/items/{item_id}/complete — Direct completion via apply_plan_item_completion() (sets claimed or needs_reverification, never verified without quiz).
  • GET .../quiz & POST .../verify — Zero-leak 2-question check; records plan_quiz:{skill_id} telemetry; on pass (≥70%) promotes verification_status="verified" & audits plan.quiz_verified.
  • POST .../swap-course, POST .../waiver, POST .../simulate — Swaps verified course & re-packs weeks, queues HITL waiver, or runs counterfactual simulation.

Python Solver & Verification Primitives

  • prereq.py: PREREQUISITE_GRAPH + topological_order() (Kahn's algorithm with required-before-preferred priority & cycle guard).
  • solver.py: compute_bkt_mastery() (priors verified=0.88, claimed=0.62, needs_reverification=0.38, unverified=0.22 updated via _bayes_update(slip=0.08, guess=0.18, transit=0.12) → bands High/Moderate/Low/Critical Gap), solve_optimal_course_selection() (bridge consolidation + Pareto budget fit), compute_cpm_dag() (ES/EF/LS/LF/slack), build_sprint_swimlanes() (module-level RCPSP packing).
  • planner.py: build_plan(), _build_grounded_narrative() (verify_text() grounding check + deterministic fallback), apply_plan_item_completion(), ensure_remedial_plan_items().
  • verification.py: generate_quiz() (exact → _PARENT_MAP → generic cascade over data/questions.json + _SUPPLEMENTAL_SKILL_QUESTIONS), check_answers() (word-boundary, negation-aware _keyword_present with HIT_RATIO=0.5, PASSING_SCORE=70).

Backend Computation (app/analytics/student_progress.py)

Readiness Formula: compute_student_readiness() computes round(0.5 * plan_pct + 0.5 * best_role_score) when plan items exist (otherwise bounded best_role_score).

Milestone Normalization: _build_milestone_series() detects legacy synthetic ladders ([20,34,45,58,67,75]), compressed (≤4h), or non-monotonic events and normalizes them into a clean monotonic baseline-to-current curve plus a Post-Plan Target point.

Adaptive Engine, Anti-Bluff Grading & Closed Loop

  • Immutable Verification Snapshot (_verification_plan): Prioritizes unverified → needs_reverification → claimed skills; extends beyond MAX_TURNS = 8 if target claims remain.
  • Live AI Authoring & Resume Probes: generation.py::author_question() uses complete_live() (no silent circuit-breaker mock swap) and marks offline fallbacks with question_source + assessment_limited. resume_probe.py synthesizes up to 2 probes (q-resume-01/02) from resume evidence.
  • Strict Anti-Bluff 3-Axis Rubric (engine.py::_reconcile_evaluation): Verdicts wrong_or_baseless (≤15), vague_superficial (≤32), partial, solid, strong. Caps question-parroting, gibberish, and word-salad bluffs; enforces composite ceiling 0.60*tech + 0.25*depth + 0.15*comm plus tech-tier caps so communication fluency cannot rescue false technical claims.
  • Adaptive Follow-ups & Difficulty: Adjusts difficulty (0/1/2) at ≥70 / <40; triggers follow-up probe when missed_keywords exist and score < 75 or depth_and_examples < 60.
  • Closed-Loop Promotion (_finalize & _promote_skills_from_summary): ≥80 promotes skill level & marks verified; ≥70 re-verifies flagged/basic skills; 45–69 marks needs_reverification; <45 marks unverified; <70 triggers ensure_remedial_plan_items(). Re-ranks JobMatch and syncs active JobApplication.match_score.

Speech Pipeline, Quality Audit & Refinement

  • POST /api/speech/transcribe & POST /api/speech/analyze: 15 MB audio cap; tries OpenAI whisper-1 → local faster-whisper (tiny) → browser Web Speech fallback. speech_analytics.py::analyze_speech_delivery() scores STAR components (45 pts), filler discipline (30 pts), and neutral pacing (25 pts).
  • GET /api/interview/questions/quality (faculty_mentor / tpo_admin): Runs quality.py::audit_question_bank() (checks ≥35 chars, no trivial "What is X?" patterns, ≥3 keywords, ≥2 outline points, valid role & taxonomy skill) + QuestionTelemetryManager().analyze_feedback_loop().
  • POST /api/interview/questions/refine (faculty_mentor / tpo_admin): Calls QuestionTelemetryManager().apply_calibration() on questions with ≥3 attempts flagging avg_score ≥ 90 (raise difficulty), avg_score ≤ 35 (lower difficulty), or avg_keyword_hit_ratio < 0.25 (keyword_review_flagged).
  • Prompt-Injection & PII Guard: Scrubs candidate text via scrub_for_llm() and sanitize_untrusted_text(); neutralized answer injections log security.prompt_injection_blocked in AuditLog.
